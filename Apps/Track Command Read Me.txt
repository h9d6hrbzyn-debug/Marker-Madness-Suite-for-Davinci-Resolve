Track Command v1.2.2
A DaVinci Resolve Script by Resolve Tools
resolve-tools.com
──────────────────────────────────────────

WHAT IT DOES
Track Command gives you full control over timeline tracks in DaVinci
Resolve. Rename tracks, reorder them, add or delete tracks, and manage
track visibility — all from a clean, dedicated panel.

WHAT'S NEW IN 1.2.2
- Counter Start now begins exactly at Start and advances by Step —
  a Start of 5 with Step 10 numbers 05, 15, 25 instead of 50, 60, 70
- Load with "Change Timeline": tracks it appends now go on the Undo
  stack, so Undo removes them and returns the timeline to how it was
  before the load
- Restore Original now restores a track whose original name was
  blank, instead of leaving a renamed track alone because there was
  nothing to compare it to
- Load Preview: selecting rows in only one column (Video or Audio)
  no longer empties the other column — nothing selected in a column
  still loads everything in that column
- Load Tracks now recognizes multi-word audio types like "5.0 Film"
  and "7.1 Film" in a saved tracks file, instead of falling back to
  mono with the type folded into the name

WHAT'S NEW IN 1.2.1
- One window only — launching it again brings the window already open
  to the front instead of starting a second copy

WHAT'S NEW IN 1.2
- Load Tracks preview now opens centered over the main window and
  always in front — Float on Top politely steps aside while the
  preview or a file dialog is open, then comes right back (fixes the
  preview getting lost on big multi-monitor setups, and a freeze
  when it slipped behind the main window)
- Track names in the preview select as full rows — click a name to
  highlight the whole line, shift/cmd-click for multiples
- Selection now chooses what loads: select rows to load only those
  tracks; nothing selected = load everything (as before)
- Load/Save file dialogs open in front of the floating window
- Preview action buttons now use the suite's standard button text
  color (they were light-gray-on-color and hard to read)

REQUIREMENTS
• DaVinci Resolve 18 or later
• macOS

INSTALLATION
1. Copy "Track Command 1.2.2.py" to:
   ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/
   Fusion/Scripts/Utility/

   (Create the Utility folder if it doesn't exist.)

2. Restart DaVinci Resolve if it is already running.

LAUNCH
From the Resolve menu bar:
   Workspace → Scripts → Utility → Track Command 1.2.2
