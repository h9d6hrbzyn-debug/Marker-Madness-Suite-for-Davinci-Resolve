WHAT IT DOES
Clip Renamer Pro renames clips in your DaVinci Resolve Media Pool in
bulk. Build a custom name from tokens — scene, take, camera, description,
and more — preview the result before committing, and apply in one click.

WHAT'S NEW IN 2.2.2
- One window only — launching it again brings the window already open
  to the front instead of starting a second copy

WHAT'S NEW IN 2.2.1
- Fixed: button labels were invisible while the window was focused.
  2.2 started deriving each label's colour from the button's face,
  which is the right rule for a surface we paint ourselves and the
  wrong one here — macOS ignores a button's background entirely and
  draws its own, bright while the window is active and grey once it
  isn't. Dark faces therefore got near-white labels, which vanished
  against that bright background exactly when you were trying to use
  the window, and reappeared the moment you clicked away. Labels are
  near-black again, matching Clipper and Track Command, which never
  had the problem.

WHAT'S NEW IN 2.2
- Buttons are legible again, matching Marker Madness 1.7. The text
  colour is now derived from each button's face rather than fixed at
  near-black, which had left white-on-pale and black-on-dark buttons
  in the same window. Green, blue and red were deepened so their
  labels clear 4.5:1 at rest and on hover.
- New "Continue from highest" — scans the current bin, finds the
  largest number already in use, and sets Start to one step past it.
  Slots a new run of clips in after an existing 010/020/030 without
  renumbering from the top.
- A live counter readout sits under the Counter row, showing the first
  three numbers your current Digits / Start / Step actually produce.
- Digits now defaults to 3, so 010 / 020 / 030 is the resting state.
- Fixed: clearing the Start field to type a new number no longer
  breaks the preview or the rename.

WHAT'S NEW IN 2.1
- New Version suffix — tick "Version" to append a version tag to every
  name in one pass, instead of typing _v1 on each clip by hand. Set the
  tag (default "_v"), the number, and how many digits:
      _v1     tag "_v", no 1, digits 1
      _v01    tag "_v", no 1, digits 2
      -v003   tag "-v", no 3, digits 3
  The version is always appended LAST — after the counter, and after
  anything the "After counter" option adds — so it stays at the end of
  the name where a version belongs.
- Step now sits on the same line as Digits and Start, where it's easy
  to find. Digits 3 / Start 10 / Step 10 gives 010, 020, 030 — numbering
  with room to slot a shot in later.
- Changed: Start is now the first number, not a multiplier. Previously
  the first value was Start × Step, so "Start: 1, Step: 10" produced
  010. Now Start means what it says — Start 10, Step 10 gives 010, 020,
  030, and Start 10, Step 2 gives 010, 012, 014.

REQUIREMENTS
• DaVinci Resolve 18 or later
• macOS

INSTALLATION
1. Copy "Clip Renamer Pro 2.2.2.py" to:
   ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/
   Fusion/Scripts/Utility/

   (Create the Utility folder if it doesn't exist.)

2. Restart DaVinci Resolve if it is already running.

LAUNCH
From the Resolve menu bar:
   Workspace → Scripts → Utility → Clip Renamer Pro 2.2.2
