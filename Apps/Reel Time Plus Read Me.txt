WHAT IT DOES
Reel Time Plus is a timecode calculator and reel timer designed for
editors and DITs. Track multiple projects, calculate running times with
break deductions, and work in any timecode format — all without leaving
your workspace.

NOTE: This is the Resolve Script (.py) version. A standalone app for
macOS and Windows is also available at resolve-tools.com/reel-time-plus.

WHAT'S NEW IN 1.3
- The act bar stays inside its frame. The coloured act blocks were
  sized against content alone while the target box was sized against
  the full runtime, so on any show with breaks the last act ran out
  over the border. Both are on one scale now, and the TV breaks or
  film leader show as the gaps between blocks
- The border is the bar's frame: green at or under target, red when
  you're over, neutral grey when no target is set
- One window only — launching it again brings the window already open
  to the front. Two windows each rewrote the entire projects file on
  save, so whichever you saved last quietly wiped the other's edits
  across every project

REQUIREMENTS
• DaVinci Resolve 18 or later (for the script version)
• macOS

INSTALLATION
1. Copy "Reel Time Plus 1.3.py" to:
   ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/
   Fusion/Scripts/Utility/

   (Create the Utility folder if it doesn't exist.)

2. Restart DaVinci Resolve if it is already running.

LAUNCH
From the Resolve menu bar:
   Workspace → Scripts → Utility → Reel Time Plus 1.3
