STUDIO LINK 1.2.1 — Modify Studio → DaVinci Resolve live bridge
Part of the Marker Madness suite

WHAT IT DOES
Watches Modify Studio's generation jobs and imports each completed image,
video, or audio file straight into a "MODIFY STUDIO" bin in your current
Resolve project — sorted into Images / Video / Audio sub-bins, within
seconds of the generation finishing. Generate on one monitor, cut on the
other. It never touches your timeline; it only stocks bins.

WHAT'S NEW IN 1.2.1
- One window only — launching it again brings the window already open
  to the front instead of starting a second bridge polling the same
  job queue

REQUIREMENTS
• Modify Studio running locally (8766/8765) OR on the QNAP
  (192.168.1.45:8790). For QNAP use, mount the share first:
  Finder > Go > Connect to Server > smb://192.168.1.45/ModifyStudio
  (imports resolve through /Volumes/ModifyStudio)
• DaVinci Resolve with an open project

INSTALL
Copy "Studio Link 1.2.1.py" into your Resolve scripts folder, then run it
from Workspace > Scripts > Utility inside Resolve.

macOS:   /Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/
Windows: C:\ProgramData\Blackmagic Design\DaVinci Resolve\Fusion\Scripts\Utility\

⚠ BLACKMAGIC CLOUD PROJECTS — TURN AUTO-IMPORT OFF
In a cloud workflow, media begins uploading the moment it lands in a bin,
carrying whatever directory it came from. Studio Link imports from the
studio share (/Volumes/ModifyStudio/...), so auto-importing into a CLOUD
project would upload share paths your collaborators can't resolve and
scramble the cloud tree.
For cloud projects the order must be: send the approved version out of
Studio → copy it into your SHOW DRIVE's renders directory → import into
Resolve FROM THE DRIVE. Uncheck "Auto-Import" and import by hand until
drive-first cloud mode ships (RESOLVE-BRIDGE.md Phase 2.5).
Local (non-cloud) projects are unaffected — auto-import is safe there.

USE
• Auto-Import (on by default): anything you generate while the link is
  open lands in the media pool automatically. (See the cloud warning above.)
• Generations from before you opened the link are NOT auto-imported —
  press "Import All Now" to pull everything Studio currently remembers.
  (Note: Studio's job list resets when the Studio app restarts.)
• Kind checkboxes filter what auto-imports (Images / Video / Audio).
• Status lights: ● Studio and ● Resolve (scripting connected).
  Studio light: green = linked · orange = reachable but needs a
  sign-in · red = unreachable (launch Modify Studio — the link
  reconnects on its own).

SIGN-IN (multi-user Studio, e.g. the QNAP)
When Studio runs with user accounts, an orange light and a sign-in row
appear in the link window. Enter your Studio name and password once —
the link keeps the session (about 6 months) in
~/.modify_studio_link_session.json. Your password itself is never
stored. The link imports YOUR generations (the account you sign in
with), matching Studio's per-user worlds.

DUPLICATE SAFETY
Studio Link remembers what it has imported per Resolve project (state
kept in ~/.modify_studio_link_state.json), so re-running it never
double-imports. Delete that file to reset the memory.

KNOWN LIMITS (1.0)
• One-way: Studio → Resolve. No timeline placement, by design.
• Files must be fully written before import; clips still uploading from
  a slow generation show "waiting on file" and import on the next pass.
