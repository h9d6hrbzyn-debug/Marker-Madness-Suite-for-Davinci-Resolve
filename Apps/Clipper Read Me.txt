WHAT IT DOES
Clipper turns your timeline markers into individual sub-clips or complete
sequences in one click. Set in/out points with a marker pair, name your
destination bin, and Clipper does the rest — with optional handle padding,
timeline ordering prefixes, and multi-track support.

WHAT'S NEW IN 1.3
- Name from markers — subclips can take the name of the first named
  marker on each clip (clip markers first, then ruler markers in the
  clip's span; stray markers on unused source footage are ignored)
- Add handles toggle — handles are OFF by default; switch on and you
  get your saved default. ★ Make Default remembers your preferred
  handle count (and custom head/tail) across launches
- Build reel (beta) — assemble the created clips into one sequence,
  in order, right after creation
- Collision-proof naming — if a timeline name is already taken the
  new one gets _02 / _03… automatically; no more blocked creations
- Clip from Range: every placement is verified; grouped/synced clips
  that Resolve's API can't place are skipped BY NAME with a flatten
  tip (copy to a spare track, flatten the copies, re-run); stray
  audio from failed placements is cleaned up automatically
- Track selection is remembered across runs and refreshes

TWO BUTTONS, TWO JOBS
- Create In/Out Clips → the VFX pull: individually named, export-
  ready plate sequences (marker names live here)
- Clip from Range → the viewing cut: one quick sequence of raw source
  clips from a track or range (flatten grouped media first)

REQUIREMENTS
• DaVinci Resolve 18 or later
• macOS

INSTALLATION
1. Copy "Clipper 1.3.py" to:
   ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/
   Fusion/Scripts/Utility/

   (Create the Utility folder if it doesn't exist.)

2. Restart DaVinci Resolve if it is already running.

LAUNCH
From the Resolve menu bar:
   Workspace → Scripts → Utility → Clipper 1.3
