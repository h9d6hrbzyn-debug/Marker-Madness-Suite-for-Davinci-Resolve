WHAT IT DOES
Clipper turns your timeline markers into individual sub-clips or complete
sequences in one click. Set in/out points with a marker pair, name your
destination bin, and Clipper does the rest — with optional handle padding,
timeline ordering prefixes, and multi-track support.

WHAT'S NEW IN 1.5.2 (fix)
- Plates were one frame short on the tail handle: ask for 12 frames of
  handle on each side and you got 12 at the head but only 11 at the tail.
  Resolve treats the end frame of a clip as exclusive, and Clipper now
  accounts for that. Every plate carries the full head and tail handles.

WHAT'S NEW IN 1.5.1 (safety fix)
- Video only could remove audio tracks from the wrong timeline in rare
  cases; Clipper now verifies the target and stops if the original
  timeline changes. Every audio-track strip is now refused unless the
  target is confirmed to be a timeline Clipper created in that run, not
  your original timeline, and currently selected in Resolve — and after
  every strip, Clipper re-checks your original timeline's audio track
  count and stops the whole run immediately (with an on-screen warning
  to undo) if it ever finds it changed.

WHAT'S NEW IN 1.5
- Copy grade — Build reel gained a "Copy grade" checkbox (enabled only
  when Build reel is on) that carries each source clip's colour grade
  onto its outer item on the finished reel, using Resolve's CopyGrades
  API. The grade lands on the same layer you'd lasso for Bypass Color
  Management, so the reel reproduces the main timeline's stack exactly:
  clean plate, compound container, grade and bypass together on the
  outer item. Bypass Color Management itself has no scripting API, so
  that step stays a manual lasso after the reel is built — the
  completion log reports how many grades copied and reminds you to
  apply it.

WHAT'S NEW IN 1.4.1
- One window only — launching it again brings the window already open
  to the front instead of starting a second copy

WHAT'S NEW IN 1.4
- Name your reel — Build reel now has its own name field. Leave it
  blank and the reel is named the way it always was
  ("<timeline> — <track> REEL"); type something and the reel is named
  exactly that. Built for VFX pulls where the reel should carry the
  scene rather than the source track — VFX 024, SC024 EXPORT, and so
  on. Repeat pulls of the same name get _02 / _03 automatically
- Build reel is out of beta — assembling the created clips into one
  sequence has been running clean and is now a standard feature

TWO BUTTONS, TWO JOBS
- Create In/Out Clips → the VFX pull: individually named, export-
  ready plate sequences (marker names live here)
- Clip from Range → the viewing cut: one quick sequence of raw source
  clips from a track or range (flatten grouped media first)

REQUIREMENTS
• DaVinci Resolve 18 or later
• macOS

INSTALLATION
1. Copy "Clipper 1.5.2.py" to:
   ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/
   Fusion/Scripts/Utility/

   (Create the Utility folder if it doesn't exist.)

2. Restart DaVinci Resolve if it is already running.

LAUNCH
From the Resolve menu bar:
   Workspace → Scripts → Utility → Clipper 1.5.2
